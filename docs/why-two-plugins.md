# なぜプラグインが2つに分かれているのか

CyberNote には、役割の違う2つのプラグインがあります。
「無料版だけで使う」なら1つ、「脆弱性アラート（Pro）まで使う」なら2つ目を追加します。
ここでは、なぜ別々になっているのかを、なるべくやさしく説明します。

---

## まず結論（一言で）

**無料版は「サイトの中を見て診断する係」、Pro接続プラグインは「外の脆弱性情報と照らし合わせる係」です。**
仕事の内容がまったく違うので、道具も分かれています。

---

## 2つのプラグイン

| | CyberNote Security Checker（無料版） | CyberNote Security Checker Pro（接続プラグイン） |
|---|---|---|
| 入手先 | WordPress.org（公式ディレクトリ） | cybernote.click（ご購入後にダウンロード） |
| 料金 | 無料 | 有料（サブスク） |
| すること | サイト内の設定・バージョンを診断（12項目） | 使用中のプラグイン・テーマを既知の脆弱性情報と毎日照合 |
| 外部通信 | なし（サイトの中だけで完結） | あり（CyberNoteのサーバーと通信） |
| 例 | 「更新が3件来ています」 | 「その更新のうち1件は"重大な脆弱性の修正"です。今すぐ更新を」 |

---

## 分かれている3つの理由

### 理由1：WordPress.org の公式ルール

WordPress.org の無料プラグインには、**「お金を払わないと使えない機能のコードを入れてはいけない」** というルールがあります
（"トライアルウェア禁止"）。

もし脆弱性アラート（有料機能）のコードを無料版に埋め込むと、このルールに違反してしまいます。
実際、CyberNote は過去に一度この指摘を受け、該当コードを削除して公開し直した経緯があります。

そのため、**有料機能のコードは無料版に一切入れず、別のプラグインとして cybernote.click から配布**しています。
これは「ルールを守って安全に公開し続けるため」の作りです。

### 理由2：脆弱性チェックは"外の情報"がないとできない

「このプラグインのこのバージョンに、どんな危険が見つかっているか」という情報は、
世界中で日々更新される**外部の脆弱性データベース**にあります。サイトの中を見るだけでは分かりません。

この照合作業は、みなさんのサイトの中ではなく、**CyberNote のサーバー側でまとめて行います**。
（サイトごとに外部データベースへ直接つなぐと、重くなったり管理が難しくなったりするためです。）

つまりPro機能は、仕組みとして「外のサーバーとやりとりする」必要があり、
「サイトの中だけで完結する」無料版とは根本的に性質が違います。

### 理由3：無料版を"軽く・安全"に保つため

無料版は「外部通信なし・常駐処理なし」で、サイトを重くしない設計を守っています。
有料機能（毎日の自動チェックや外部通信）を同じプラグインに混ぜると、この良さが崩れます。

役割ごとに分けておくことで、
**無料版はいつまでも軽く安全に、Pro機能は必要な人だけが追加する**、という形にできます。

## 使うときの流れ

```
【無料版だけで使う場合】
  WordPress.org から「CyberNote Security Checker」を入れる → 診断が使える

【脆弱性アラートまで使う場合】
  上に加えて、cybernote.click から「Pro接続プラグイン」を入れる
    → ライセンスキーを1回入力
    → あとは毎日自動でチェック。危険が見つかれば管理画面に日本語で表示
```

Pro接続プラグインを入れると、無料版の「脆弱性アラート」メニューが
"案内ページ"から"実際の結果ページ"に自動で切り替わります。
（無料版が無くても、Pro接続プラグイン単体で動きます。）

## よくある質問

**Q. 2つ入れると重くなりませんか？**
いいえ。無料版は今まで通り。Pro接続プラグインの照合はCyberNoteのサーバー側で行い、
サイト側は結果を受け取って表示するだけなので、負担はごくわずかです。

**Q. 情報はどこまで送られますか？**
使用中のプラグイン・テーマの名前とバージョン、WordPress・PHPのバージョン、サイトURLだけです。
記事の内容やユーザー情報などの個人情報は送りません。

**Q. なぜ最初から1つにまとめてくれないの？**
WordPress.org のルール（理由1）で、有料機能を無料版に同梱できないためです。
分かれているのは「手抜き」ではなく、**ルールを守り、無料版を安全に保つための正しい作り**です。

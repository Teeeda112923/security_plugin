# 診断結果の見方

Site Security Checker の診断結果は **3段階のステータス** で表示されます。それぞれの意味と、優先度の考え方を説明します。

---

## 3つのステータス

### 🔴 要対応

**今すぐ対応することをお勧めします。**

放置すると「ログイン情報が盗まれる」「サイトのファイルを書き換えられる」など、実害につながる可能性があります。表示された対処手順に従って、できるだけ早く対応してください。

> 「要対応」と表示される項目は、セキュリティ上の影響が大きいもの（例：HTTPSを使っていない、管理画面からファイルを直接編集できる状態になっている）に限定しています。

### 🟡 改善推奨

**できれば対応を検討してください。**

すぐに被害が起きるわけではありませんが、攻撃の足がかりになりやすい設定です。他の対応が終わったあと、余裕があるときに確認してください。

> 稼働中のサイトで変更にリスクを伴う項目（データベース接頭辞の変更など）は、「改善推奨」以上には上げず、むやみに変更を急かしません。

### ✅ 問題なし

**この項目は適切に設定されています。**

現時点では対応は不要です。定期的に再診断して、ステータスが変わっていないか確認することをお勧めします。

---

## 診断結果の読み方（専用管理画面）

### サマリーエリア（画面上部）

画面上部のサマリーには、全10項目の内訳が表示されます。

```
要対応 〇件  改善推奨 〇件  問題なし 〇件
```

「要対応 0件」になることを目指しましょう。「改善推奨」はすぐに対応しなくても問題ありませんが、なくせると理想的です。

### 各診断カード

各項目はカード形式で表示されます。カードには次の情報が含まれます。

| 表示 | 内容 |
|---|---|
| 項目名 | 何を診断しているか |
| 現在の状態 | 実際の設定値や検出結果 |
| コメント | なぜ問題か・何をすればよいか |
| `›`（詳細ボタン） | 対応手順・リスク・参考リンクを展開表示 |

### `›` ボタンを押すと何が見えますか？

各カードの右側にある `›` をクリックすると、ガイドパネルが展開されます。

- **対応手順** — 具体的な操作ステップ（wp-config.php の編集方法など）
- **対応しないと…** — 放置した場合のリスクの説明
- **詳細はこちら** — WordPress公式ドキュメントなど参考リンク

---

## 優先順位の考え方

> **まず「要対応」をゼロにする → 次に「改善推奨」を減らす**

「改善推奨」がすべて残っていても、「要対応」がゼロなら基本的なセキュリティレベルは確保できています。焦らず、一つずつ対応していきましょう。

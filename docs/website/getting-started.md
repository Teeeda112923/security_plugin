# インストールから最初の診断まで

このページでは、Site Security Checker をインストールして、最初の診断結果を確認するまでの手順を説明します。

---

## 手順1：プラグインをインストールする

### 自動インストール（おすすめ）

1. WordPress管理画面の左メニューから **「プラグイン」→「新規追加」** を開きます
2. 右上の検索窓に **「Site Security Checker」** と入力します
3. 「今すぐインストール」ボタンをクリックします
4. インストールが完了したら **「有効化」** をクリックします

### ZIPからインストールする場合

1. [WordPress.orgのプラグインページ](https://wordpress.org/plugins/site-security-checker/) からZIPファイルをダウンロードします
2. WordPress管理画面の **「プラグイン」→「新規追加」→「プラグインのアップロード」** を開きます
3. ダウンロードしたZIPファイルを選択して「今すぐインストール」をクリックします
4. 「有効化」をクリックします

---

## 手順2：診断結果を確認する

有効化すると、2か所で診断結果を確認できます。

### ダッシュボードウィジェット（かんたん確認）

WordPress管理画面のトップ（ダッシュボード）を開くと、**「セキュリティ診断」ウィジェット** が表示されます。

- 確認が必要な件数が一目でわかります
- 「優先対応が必要な項目」が上部にリストアップされます
- 「詳細画面を開く」から専用ページへ移動できます

### 専用管理画面（詳細確認）

左メニューに **「セキュリティ診断」** という項目が追加されます。ここから全10項目の詳細な診断結果を確認できます。

---

## 手順3：再診断する

ダッシュボードウィジェット右上の **「再診断」ボタン**、または専用管理画面の **「再診断する」ボタン** をクリックすると、ページを再読み込みせずに最新の状態を確認できます。

設定を変更した後は、再診断ボタンで結果が更新されたことを確認してください。

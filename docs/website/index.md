# Site Security Checker — 使い方ガイド

**WordPressのセキュリティを、専門知識ゼロで確認できるプラグインです。**

---

## このプラグインで何ができますか？

WordPressで運営しているサイトが「今、どのくらい安全か」を10項目で診断します。

- パソコンの操作に慣れている方なら、誰でも使えます
- 専門用語はできる限り使わず、平易な日本語で説明します
- 診断はサイト内だけで完結し、**外部へのデータ送信はゼロ**です
- プラグインが自動でサイトの設定を変えることは**一切ありません**

---

## 3つの特徴

### 1. 10秒で診断できる

管理画面を開くだけで自動的に診断が走ります。「再診断」ボタンを押せば、いつでも最新の状態を確認できます。

### 2. 「何をすればいいか」がすぐわかる

診断結果は **3段階（要対応・改善推奨・問題なし）** で表示されます。各項目には「なぜ問題なのか」「具体的にどう対処するか」が日本語で書かれています。

### 3. サイトを重くしない

常時起動するスキャンや監視機能は持っていません。ダッシュボードを開いたときだけ診断を実行するので、サイトの表示速度に影響しません。

---

## 診断する10項目

| カテゴリ | 項目 |
|---|---|
| **A. バージョン鮮度** | WordPress本体 / PHPバージョン / プラグイン・テーマの更新 |
| **B. ハードニング設定** | デバッグ表示 / ファイル編集機能 / 管理者ユーザー名 / 常時HTTPS / データベース接頭辞 / XML-RPC / REST APIユーザー名列挙 |

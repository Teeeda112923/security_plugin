# CyberNote Security Checker Pro（接続プラグイン）

**購入者向けに cybernote.click で配布する**プラグインです。
WordPress.org の無料版とは別物で、配布版ZIPには**同梱しません**（.distignore で除外済み）。

## 機能（B2: 実装済み）

- ライセンスキーを1回入力するだけの初期設定（保存時に接続テストを兼ねてスキャン実行）
- 毎日の自動スキャン（WP-Cron・深夜3時台に分散）
- 管理画面「脆弱性アラート」に結果を日本語で表示
  - 深刻度（重大/高/中/低）・脆弱性の種類（XSS等）・推奨する対処・CVE番号・参考リンク
  - 修正版がある場合は「更新画面を開く」ボタン
  - 0件なら「既知の脆弱性は見つかりませんでした」
- 無料版が有効な場合は「セキュリティ診断」メニュー配下に表示され、
  無料版のPro案内ページを実データ画面に置き換える。無料版が無くても単体で動作
- 送信するのはプラグイン・テーマの名前とバージョン、WP/PHPバージョン、サイトURLのみ
  （画面にもその旨を明記）

## テスト

```bash
php pro-plugin/tests/run-tests.php   # 28項目・WordPress不要で動く
```

## 配布手順

1. `cybernote-security-checker-pro/` フォルダをZIP化
2. cybernote.click の購入完了ページ／マイページからダウンロードできるよう設置
3. 購入者への案内: 「プラグイン > 新規追加 > アップロード」でインストール →
   有効化 → 「脆弱性アラート」画面でライセンスキーを入力

## 動作の前提

- cybernote.click に backend/cybernote-api が設置・有効化されていること
- ライセンスキーが cybernote.click 側に登録されていること
  （暫定: 設定 > CyberNote API で手動登録。B3でLemon Squeezy自動発行に置き換え）
